# Sample-image attribution

The photographs in `examples/images/` retain their original Creative Commons licences. These media licences are separate from the application code and dependency licences. The photographers do not endorse this application or its model-generated findings. Keep these credits and the applicable licence when reusing the photographs. Share-alike conditions apply to adaptations of the two BY-SA images.

The source file pages and/or Wikimedia Commons' official `imageinfo` API were checked on **23 September 2026**. Each bundled photograph is the Commons 1280-pixel-wide thumbnail, copied without further alteration; watermarks remain intact. Model preprocessing separately converts the image to RGB JPEG at quality 90. Source identifiers, image dimensions and SHA-256 checksums are recorded in [`examples/sources.json`](examples/sources.json).
