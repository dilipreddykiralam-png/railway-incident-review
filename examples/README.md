# Example inputs and model outputs

These three Creative Commons photographs and their genuine local **Qwen2.5-VL 7B** responses demonstrate the application's pipeline. Human verification is pending; they are not expert-labelled evaluation data.

- [View images, findings, limitations and timings](../docs/SAMPLE_RESULTS.md).
- [Read the image attributions and licences](../ATTRIBUTION.md).
- `sources.json` records image provenance, dimensions and checksums.
- `outputs/` contains the full original pipeline records and runtime metadata.

From the project root, after setup, run `python examples/run_examples.py` to repeat the examples into a new timestamped local output folder. The committed outputs are never overwritten.
